# Cantera TCD Documentation

This document provides the entry point for the simplified transport model,
thickened flame model, and stretched-thickened flame model implemented in this
Cantera fork.

The full technical documentation is provided in:

[`cantera_tcd_documentation.pdf`](cantera_tcd_documentation.pdf)

## Contents of the PDF

The PDF describes:

* The simplified transport model formulation.
* Backend implementation details in Cantera.
* Python frontend usage.
* The thickened flame model implementation.
* The stretched-thickened flame model implementation.
* Validation cases and figures.
* Known limitations.
